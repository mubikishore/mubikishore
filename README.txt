MUBIKISHORE — EASY CONTENT-MANAGED SITE

The site is designed so you do not need to edit code.

Once connected to GitHub + Netlify:
1. Open yoursite.com/admin/
2. Log in
3. Choose Work / Projects, Other Things, Store, or Site Settings
4. Add/edit/upload
5. Publish

For a new film: Work / Projects → New → title/date/role → upload hero → upload gallery → add video link → Publish.

For photos/BTS: Other Things → New → choose type → upload image → Publish.

For Store: Store → New → upload product image and details.

Setup requires GitHub and Netlify once. After that, daily editing is visual.
